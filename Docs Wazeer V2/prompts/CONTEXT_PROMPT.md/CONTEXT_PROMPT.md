# Context Prompt — وزير Production Hardening Sprint
**استخدم الملف ده كأول رسالة لأي Coding Agent (Claude Code) هيشتغل على الـ Sprint ده.**

---

أنت بتشتغل على `Wazir-Pro` (وزير) — مساعد ذكاء اصطناعي شخصي، React 19 + TypeScript + Vite 6 + Express، محلي-أولًا (IndexedDB). المشروع شغال ومنشور فعليًا (`amoun.100milliondev.com`)، **مش مشروع بيتبني من الصفر.**

## قبل ما تكتب أي سطر كود
1. اقرأ `PRD.md` — فيه توضيح إن أي مواصفات قديمة بخصوص FastAPI/SLM مخصص/Redis **ملغاة رسميًا** ومتجاهلة تمامًا لو لقيتها في أي مكان.
2. اقرأ `Spec.md` — فيه القرارات التقنية والأولويات مبنية على قياس فعلي (`vite build`)، مش تخمين.
3. القرار الاستراتيجي المتخذ بالفعل: **Refactor، مش Rewrite.** ممنوع تقترح إعادة بناء من الصفر — الكود الحالي سليم (`tsc --noEmit` نظيف)، والمشكلة تنظيم تحميل مش تصميم أساسي.

## قاعدة صارمة واحدة
**ممنوع** تعمل ملفات patch مؤقتة زي `fix_*.cjs` أو `patch_*.sh` في جذر الريبو (زي اللي موجودة حاليًا ومسببة فوضى). أي تعديل بيتم مباشرة في الملف المصدري، بـ commit واضح، ويتحذف أي أداة مؤقتة استخدمتها فورًا بعد الاستخدام.

## نطاق الـ Sprint ده بالظبط (بالترتيب)

### 1. Code Splitting (أعلى أولوية)
حوّل كل الـ Views في `src/App.tsx` (ما عدا `HomeView`) لـ `React.lazy` + `Suspense`. التفاصيل والكود الكامل في `Spec.md` قسم 1. الهدف: الحزمة الأساسية تنزل من 778KB gzip لأقل من 250-300KB. تحقق بـ `npx vite build` بعد التعديل وقارن الأرقام.

### 2. توحيد استدعاء ipapi.co
دلوقتي بينادى 3 مرات منفصلة (`useBanGuard.ts` + مرتين في `LoginModal.tsx`). ادمجهم في service واحد بـ cache للجلسة، وأجّل الاستدعاء لبعد أول render. التفاصيل في `Spec.md` قسم 2.

### 3. Rate Limiting على الـ proxy
كل الراوترز في `src/server/llm-routers/` مفيهاش أي حماية. ضيف rate limiting بسيط (IP-based) على مستوى `src/server/llm-routers/index.ts`.

### 4. تحديث model IDs
دور على `src/services/aiGateway.ts` على `claude-3-5-sonnet-20240620` وأي موديل قديم مشابه، وحدثهم.

### 5. تنظيف جذر الريبو
انقل أو امسح كل ملفات `fix_*.cjs` و `patch_*.sh` من الجذر (27 ملف تقريبًا). لو محتاج تفاصيل منها لتوثيق تاريخي، لخصها في `docs/` بدل ما تسيبها زي ما هي.

## حاجات **متبعتش تلمسها** في الـ Sprint ده
- نظام الحظر (Archon/Excommunicado) — محتاج قرار منفصل من مُعلم قبل ما يتصلح أو يتشال، مش جزء من الـ Sprint ده.
- ميزات Multi-Agent Projects والذاكرة طويلة المدى — دي في `AMOUN_BLUEPRINT_PROJECTS_MEMORY.md` منفصل، مرحلة تانية.
- الهوية البصرية (Eye of Horus / الاسم) — قرار برانديج، مش تقني.

## معيار النجاح
شغّل `npx vite build` قبل وبعد، وسجّل الفرق في حجم الحزمة الأساسية بالأرقام. الهدف مش "حسيت إنه بقى أسرع" — الهدف رقم واضح تقدر تقوله لمُعلم.
